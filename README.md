# Zoetis Sales Dashboard

افتح الداشبورد من أي متصفح، بما فيه Safari على الآيفون:

https://mohamedmemo8449-web.github.io/zoetis-dashboard/

## تحديث الداشبورد

بعد تعديل الملف الأصلي `05_المخرجات/Dashboard_Mohamed_Sales.html`، انسخه إلى `05_المخرجات/dashboard-pages/index.html`. ثم افتح مستودع GitHub، واختر **Code → Add file → Upload files**، وارفع ملف `index.html` المحدّث، ثم اضغط **Commit changes** على فرع `main`. GitHub Actions سينشر النسخة الجديدة تلقائيًا.

## البيانات والخصوصية

المستودع والموقع عامّان، وملف الداشبورد يتضمن بيانات المبيعات والتارجت داخله. لا تضف ملفات المشروع أو Numbers أو ملفات CSV المصدر إلى هذا المستودع.
